# HemelaFitHub — Home Fitness Equipment Store

A bilingual (English / 中文) e-commerce site for small, home-friendly fitness equipment.
Built with **Next.js 14 + TypeScript + Tailwind CSS**, with a full **cart + Stripe checkout** payment system.

Design/structure is based on the reference standalone site (`hemela-site-backup`), adapted
for a consumer fitness brand with an integrated, real payment flow (the reference site had
inquiry-only links and no payment).

## Features

- 🏠 Home, Shop, Product Detail, About, Contact pages
- 🌐 Bilingual EN/中文 toggle (reuses the `t(en, zh)` language pattern from the reference)
- 🛒 Live cart (slide-out drawer) with add / remove / quantity + localStorage persistence
- 💳 **Secure payment via Stripe Checkout** (credit cards, Apple Pay, Google Pay)
- 📦 6 product categories · 18 products with prices, ratings, specs, features
- 🖼️ Self-contained SVG placeholder images (no external image dependencies)

## Quick start

```bash
npm install
npm run dev       # http://localhost:3000
```

Production build:

```bash
npm run build
npm start
```

## Configure payments (Stripe)

1. Create an account at <https://dashboard.stripe.com>.
2. Copy your **Secret key** (`sk_test_...` for testing, `sk_live_...` for real payments).
3. Copy your **Publishable key** (`pk_test_...` / `pk_live_...`).
4. Create `.env.local` from the example:

```bash
copy .env.local.example .env.local
```

Then fill in:

```env
STRIPE_SECRET_KEY=sk_test_xxxxxxxxxxxxxxxxxxxx
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_xxxxxxxxxxxxxxxxxxx
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

> Important: `STRIPE_SECRET_KEY` is required. Without it the checkout API returns a
> friendly "Payment is not configured" message instead of crashing.

## How the payment flow works

1. User adds items → cart stored in `localStorage`.
2. Click **Checkout Securely** → `POST /api/checkout` (server-side).
3. Server resolves cart items against the catalog, builds Stripe line items, and creates a
   `checkout.session` (payment mode, with shipping/billing address collection).
4. Browser is redirected to the hosted Stripe Checkout page.
5. On success → `/checkout/success` (clears cart); on cancel → `/checkout/cancel`.

The checkout route lives at `src/app/api/checkout/route.ts`.

## Product data

Edit `src/data/products.ts` to change products, prices (in **cents**), categories, and
testimonials. Company info (email/phone/address) is also there.

## Placeholder images

SVG placeholders are generated by `scripts/make-images.js`:

```bash
node scripts/make-images.js
```

Replace files in `public/images/products/` with real product photos when ready.

## Notes on prices

Prices are stored in USD cents (e.g. `2499` = $24.99). Stripe uses `unit_amount` in the
minor currency unit, so the values map directly. To change currency, edit the `currency`
field in the checkout route and in `formatPrice` (`src/lib/cart.tsx`).
